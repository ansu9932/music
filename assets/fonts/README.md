# Inter font

Binary font files cannot be generated by the agent. Download the Inter family
(SIL Open Font License) and place these four files in this directory so the
`pubspec.yaml` font declaration resolves:

- `Inter-Regular.ttf`   (weight 400)
- `Inter-Medium.ttf`    (weight 500)
- `Inter-SemiBold.ttf`  (weight 600)
- `Inter-Bold.ttf`      (weight 700)

Source: https://github.com/rsms/inter/releases (use the "Inter Desktop" `.ttf`
files, or the static TTFs from the Google Fonts mirror).

On macOS the app falls back to the system **San Francisco** family when Inter
is unavailable, so the app still runs without these files — text simply renders
in the platform default until they are added.
